هذا مقال نموذجي. احذفه أو عدّله لتبدأ مدونتك.

## كيف تضيف مقالًا جديدًا؟

1. افتح مجلد `src/content/articles/` في مستودع GitHub.
2. اضغط **Add file ← Create new file**.
3. اكتب المحتوى وأضف الحقول في أعلى الملف، ثم احفظ.

كل مقال يظهر تلقائيًا في الرئيسية، وفي تصنيفه، وفي خلاصة RSS.

## الحقول

| الحقل | إلزامي | الوصف |
|---|---|---|
| `title` | نعم | عنوان المقال |
| `description` | لا | وصف قصير يظهر في نتائج البحث |
| `date` | نعم | تاريخ النشر بصيغة `YYYY-MM-DD` |
| `category` | نعم | التصنيف — أي كلمة تختارها |
| `url` | لا | رابط الأداة — يظهر زر «زيارة الأداة» |
| `featured` | لا | `true` = يظهر في قسم «مميزة» |
